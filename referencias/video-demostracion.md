Para publicar el video, verificar contenido, vigencia, ausencia de datos clínicos identificables y reproducción sin sesión privada. Preferible enlace embed de YouTube o Vimeo. Para un MP4 alojado por el cliente se usa el reproductor HTML con controles, sin reproducción automática.
